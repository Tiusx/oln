## 基础语法回顾

Markdown 是一种轻量级标记语言，让你专注于内容本身。

### 标题

使用 `#` 号表示标题，从一级到六级。

### 强调

- **粗体**：`**粗体**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`

### 列表

无序列表和有序列表都很简单：

1. 第一项
2. 第二项
3. 第三项

### 引用

> 好的文章不是写出来的，是改出来的。

### 代码

行内代码用反引号：`code`。

代码块用三个反引号：

```python
def hello():
    print("Hello, World!")
```

## 进阶技巧

### 链接和图片

链接：`[文字](URL)`
图片：`![替代文本](图片URL)`

### 表格

| 功能 | 支持 |
|------|------|
| 标题 | Yes |
| 列表 | Yes |
| 代码 | Yes |

## 写作建议

1. 保持段落简短
2. 使用小标题组织内容
3. 适当使用列表和代码块
4. 写完后通读一遍
