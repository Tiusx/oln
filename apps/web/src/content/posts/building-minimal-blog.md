## 为什么选择极简？

互联网上有太多信息过载的网站。我想做一个不一样的——纯粹为了阅读而设计的博客。

## 技术栈

- **Astro** — 静态站点生成，支持服务端渲染
- **Tailwind CSS v4** — CSS-first 配置
- **Cloudflare Pages** — 边缘部署，全球加速

## 设计原则

1. 无卡片、无阴影、无圆角容器
2. 纯黑白灰 + 少量强调色
3. 大量留白，让文字呼吸
4. 响应式设计，移动端优先
